# تطبيق مَسار | Masar 🎯
### رفيق طالب الثانوية العامة والمطور المستقبلي (مخصص لـ عبدو)

أهلاً بك يا عبدو! هذا التطبيق تم تصميمه وبرمجته خصيصاً ليناسب جدولك وظروفك كطالب ثانوية عامة مصري يطمح لدخول **كلية الحاسبات والذكاء الاصطناعي**، ويدير في نفس الوقت قنوات أوتوميشن لليوتيوب ويتعلم مهارات جديدة.

---

## 🌟 مميزات التطبيق المصممة لك:

1. **الصلوات والبركة أولاً 🕌**:
   - حساب فلكي دقيق لمواقيت الصلاة في مصر (الهيئة المصرية العامة للمساحة).
   - عداد تنازلي للصلاة القادمة وتنبيهات صوتية هادئة.
   - متابعة ورد القرآن اليومي (صفحة بعد كل صلاة) وأذكار الصباح والمساء لحماية هدوئك النفسي ومنع التوتر.

2. **نظام اليوم الذكي (نزول سناتر vs أونلاين ومذاكرة منزلية) 🎒/💻**:
   - **يومي النزول**: جدول مخصص لمواعيد السناتر والمواصلات، وقائمة فحص حقيبة الدروس (المذكرات، الآلة الحاسبة، الشيتات).
   - **أيام الأونلاين**: جدول مهام مركز، وقائمة بمحاضرات المنصات والواجبات.
   - **مؤقت بومودورو ذكي (Deep Work)**: 50 دقيقة تركيز تام + 10 دقائق استراحة مع أصوات تنبيه وسجل للجلسات المنجزة.

3. **مختبر أوتوميشن اليوتيوب وتعلم الـ AI 🎬🤖**:
   - لوحة كانبان (Kanban) لخط إنتاج الفيديوهات (أفكار 💡 ➔ سكريبت ✍️ ➔ توليد بالـ AI 🤖 ➔ مونتاج 🎬 ➔ منشور 🚀).
   - **مؤشر حماية وقت الثانوية**: سقف أمان ذكي (45-60 دقيقة يومياً كحد أقصى) لتستمتع بشغفك التقني دون التأثير على مذاكرة الثانوية.
   - سجل تراكمي لخطواتك في تعلم البرمجة والذكاء الاصطناعي تحضيراً لكلية حاسبات.

4. **العادات ودورات النوم والترويح المنضبط ⚡🌙☕**:
   - متتبع العادات اليومية مع عداد الأيام المتتالية (Streaks).
   - **حاسبة دورات النوم (Sleep Cycles)**: تحسب لك أفضل أوقات للاستيقاظ بنشاط بدون كسل (دورات 90 دقيقة) وضبطها مع صلاة الفجر.
   - **سجل الترويح (Guilt-Free Leisure)**: تسجيل الخروجات وتجديد الطاقة بدون جلد الذات.

5. **المستشار الأكاديمي الذكي 🤖**:
   - يقدم نصائح ديناميكية فورية بناءً على إنجازك اليومي، ومجهز بكود جاهز للربط مع **Google Gemini API** مستقبلاً!

6. **حفظ البيانات والأمان 💾**:
   - كل بياناتك محفوظة محلياً على جهازك (Offline LocalStorage).
   - ميزة تصدير واستيراد نسخة احتياطية (JSON) لتنقل بياناتك لهاتفك أو لأي جهاز آخر.

## 🚀 كيفية تشغيل واستخدام التطبيق:

### الطريقة الأسهل (بنقرة واحدة على ويندوز):
1. افتح المجلد: `C:\Users\abdos\.gemini\antigravity\scratch\masar-app`
2. اضغط مرتين على ملف: **`run_app.bat`**
3. سيفتح التطبيق تلقائياً في متصفحك الافتراضي (Edge أو Chrome) على الرابط: `http://localhost:5500`

### تثبيته كتطبيق مستقل (PWA App):
- عندما يفتح في Google Chrome أو Microsoft Edge، ستجد أيقونة صغيرة في شريط العنوان أعلى المتصفح تسمى **"تثبيت التطبيق / Install App"** أو (علامة كمبيوتر عليها سهم).
- اضغط عليها وسينزل التطبيق كأيقونة مستقلة على سطح المكتب وشريط المهام مثل أي برنامج أصلي في الويندوز!

## 🛠️ هيكلية الكود البرمجي (Clean Architecture):

تم تنظيم المشروع بكود نظيف جداً ومقسم لمودولات (Modern ES Modules) لتتعلم منه في رحلتك البرمجية:

```
masar-app/
│
├── index.html                 # واجهة المستخدم الرئيسية بتصميم RTL و Tailwind CSS
├── styles/
│   └── main.css               # استايلات Glassmorphism والمؤثرات البصرية والخطوط
│
├── src/
│   ├── app.js                 # المحرك الرئيسي وربط الأحداث والنوافذ المنبثقة
│   ├── services/
│   │   ├── storage.js         # خدمة التخزين المحلي والنسخ الاحتياطي (Backup/Restore)
│   │   └── prayers.js         # محرك حساب مواقيت الصلاة الفلكي لمصر والصوتيات
│   │
│   └── modules/
│       ├── thanawya.js        # منطق الثانوية، أوضاع النزول والأونلاين، ومؤقت البومودورو
│       ├── youtube_ai.js      # خط إنتاج فيديوهات اليوتيوب وسجل تعلم البرمجة
│       ├── habits.js          # العادات، حاسبة دورات النوم، ومؤشر الإنجاز
│       └── ai_advisor.js      # المستشار الذكي والواجهة المجهزة لـ Gemini API
│
├── manifest.json              # إعدادات الـ PWA للتثبيت على الأجهزة
├── sw.js                      # Service Worker للعمل بدون إنترنت
├── serve.ps1                  # خادم ويب محلي خفيف بالـ PowerShell
└── run_app.bat                # مشغل التطبيق السريع لويندوز
```

## 💡 أفكار يمكنك برمجتها وتطويرها في التطبيق لاحقاً:
1. **ربط Gemini API**: أدخل مفتاحك في `src/modules/ai_advisor.js` ليقوم الذكاء الاصطناعي بتحليل درجات امتحاناتك وإعطائك خطة مراجعة أسبوعية.
2. **بوت تلجرام للمهام**: عمل سكريبت بايثون يرسل لك إشعاراً على تليجرام بالمهام العاجلة وصلاة الفجر.
3. **مزامنة مع Google Sheets أو Notion**: لتصدير قائمة مشاريع قنوات اليوتيوب تلقائياً.

بالتوفيق يا عبدو، وأعلى الدرجات في الثانوية العامة وبداية موفقة في كلية حاسبات وذكاء اصطناعي إن شاء الله! 🌟
